# profilekit archive

This repository preserves the final compiled export of the Ardenne Institute for
Speech and Language profile database before its June 2025 decommissioning.

- `export/profilekit.c` - Cython-generated C artefact (Cython 3.0.11).
- `export/SYMBOL_MANIFEST.txt` - inventory of the symbols the export must carry.
- `export/build_info.json` - build metadata.

The Python source used to generate the artefact was deleted together with the old
database; only this compiled copy survives. The export is authoritative for contact
identifiers and publication venue/DOI metadata.
